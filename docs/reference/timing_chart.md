# Nif timing plot

**\[experimental\]**

## Usage

``` r
timing_chart(x, id = NULL, analyte = NULL, ...)
```

## Arguments

- x:

  A nif object.

- id:

  The IDs to plot.

- analyte:

  The analytes to plot.

- ...:

  Further parameters.

## Value

A ggplot object.

## Details

Plot absolute times of administrations and observations.
