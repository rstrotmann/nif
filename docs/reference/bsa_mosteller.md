# Body surface area (Mosteller formula)

Source: Mosteller RD. Simplified calculation of body-surface area. N
Engl J Med. 1987 Oct 22;317(17):1098.
[doi:10.1056/NEJM198710223171717](https://doi.org/10.1056/NEJM198710223171717)

## Usage

``` r
bsa_mosteller(weight, height)
```

## Arguments

- weight:

  Body weight in kg, as numeric.

- height:

  Body height in cm, as numeric.

## Value

BSA in m^2
