# Plot time metrics against each other for observations

Plot time metrics against each other for observations

## Usage

``` r
time_plot(
  obj,
  xtime = "TIME",
  ytime = "TAD",
  analyte = NULL,
  max_time = NULL,
  color = "CHECK",
  ...
)
```

## Arguments

- obj:

  A nif object.

- max_time:

  The maximum time as numeric.

- ...:

  Further graphical parameters.

## Value

A ggplot object.
